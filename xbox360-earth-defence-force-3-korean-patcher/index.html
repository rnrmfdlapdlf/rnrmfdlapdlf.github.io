2017년, 하늘을 뒤덮은 외계 우주선과 함께 거대 생물이 도시를 습격합니다. 지구방위군 EDF의 대원이 되어 수많은 무기로 침략자에 맞서는 3D 액션 슈팅을 이제 한국어로 즐겨 보세요.

GitHub 다운로드

패치 기능

일본판 ISO에 한국어 번역을 넣고 새 ISO로 다시 묶어 줍니다.

  • 메뉴·미션

    방위군 본부 메뉴와 게임 설정, 미션 목록과 브리핑을 한글로 보여 줍니다.

  • 무기

    장비 선택 화면의 무기 이름과 성능, 설명을 한글로 옮겼습니다.

  • UI 이미지

    타이틀 로고와 로딩 화면의 무기 소개·조작 안내 이미지를 한글로 바꿨습니다.

  • 자동 재패킹

    ISO와 xextool을 고르고 버튼을 누르면 원본 옆에 한글판 ISO가 만들어집니다.

스크린샷

한글패치를 적용한 실제 게임 화면입니다. 누르면 크게 볼 수 있습니다.

패치 방법

Windows용 패처에 ISO와 xextool을 끌어다 놓고 버튼 한 번이면 끝납니다.

  1. 패처 받기

    다운로드 페이지에서 zip을 받아 압축을 풀어 주세요. (Windows 10 이상)

  2. 끌어다 놓기

    일본판 ISO와 xextool.exe를 패처 창에 끌어다 놓거나 눌러서 고릅니다.

  3. 패치 시작

    원본과 같은 폴더에 원본 파일명_repacked.iso가 만들어집니다.

  • 게임 데이터는 들어 있지 않습니다. 직접 가지고 있는 정품 일본판 게임 ISO가 필요합니다.
  • xextool 6.3은 직접 준비해 주세요. (다운로드)
  • 번역은 AI 번역을 바탕으로 했습니다.

비영리 팬 번역 프로젝트이며, 원작의 저작권은 권리자에게 있습니다. 패치 사용으로 생기는 문제에 대해 책임지지 않습니다.
