스크린샷

한글패치를 적용한 실제 게임 화면입니다. 누르면 크게 볼 수 있습니다.

패치 방법

xdelta 패치 파일을 원본 게임 파일에 적용합니다.

  1. 패치 받기

    다운로드 페이지에서 zip을 받아 압축을 풀면 .xdelta 파일이 나옵니다.

  2. xdelta 적용

    원본 SoulCalibur [58410904] 파일에 xdelta3나 다른 xdelta 패치 프로그램으로 적용합니다.

  3. 게임 실행

    새로 만들어진 파일을 실행합니다. 게임 언어는 영어로 두면 한글이 나옵니다.

xdelta3.exe -d -s "SoulCalibur [58410904]" "SoulCalibur-korean-v10-museum-gallery-r5.xdelta" "SoulCalibur-korean-v10-museum-gallery-r5"
  • 게임 데이터는 들어 있지 않습니다. 직접 가지고 있는 정품 XBLA 소울칼리버 게임 파일이 필요합니다.
  • 수정하지 않은 원본에만 적용됩니다. 이전 버전의 한글패치를 적용한 파일에는 쓸 수 없습니다.
  • xdelta3는 직접 준비해 주세요. (다운로드)
  • Xenia에서 동작을 확인했습니다.

비영리 팬 번역 프로젝트이며, 원작의 저작권은 권리자에게 있습니다. 패치 사용으로 생기는 문제에 대해 책임지지 않습니다.
